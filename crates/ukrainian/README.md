# ukrainian

Ukrainian inflection for Rust, learned from Wiktionary by [morphe](https://github.com/gold-silver-copper/morphe).
Inflects any word, known or made up. The `_scored` functions give every candidate with a confidence.

Generated from the Kaikki Ukrainian dump of 2026-10-03. Do not edit by hand: change the config in morphe and regenerate.

## Example

```rust
use ukrainian::*;
println!("{}", noun("книга", Case::Genitive, Number::Plural));
println!("{}", noun("стіл", Case::Locative, Number::Singular));
println!("{:?}", noun_gender("ніч"));
println!("{}", verb("писати", Tense::Present, Person::First, Number::Singular));
println!("{}", verb_past("бути", GenderNumber::Feminine));
println!("{}", adj("гарний", Case::Dative, GenderNumber::Feminine, Animacy::Inanimate));
let plain = Ukrainian::default().marks(false);
println!("{}", plain.noun("мати", Case::Vocative, Number::Singular));
// Citations pin principal parts: nominative and genitive singular.
println!("{}", noun("кіт, кота", Case::Instrumental, Number::Singular));
```

Input matching ignores stress marks and treats ’ and ʼ as the apostrophe '.
Output carries stress marks where Wiktionary has them (`marks(false)` removes
them). Unknown words get their stress predicted from similar words, which is
often wrong.

## How it works

Each attested form is stored as an edit tree from the lemma. A lemma's edits across all cells make its inflection class. A suffix tree over the word, read from its end and pruned by a description-length test, predicts the class of any word. Known words the tree gets wrong are kept in a small lexicon. Confidences are smoothed counts; variant weights follow Wiktionary's listing order (1, 1/2, 1/3…, nonstandard forms a tenth of that).
